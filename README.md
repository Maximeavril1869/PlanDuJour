# PlanDuJour

Petite app (PWA) de plan du jour pour iPhone et iPad : des contraintes saisies une fois, un plan qui se recale autour des rendez-vous. Données stockées uniquement sur l'appareil, sans compte.

- Règles de développement : [CONVENTIONS.md](CONVENTIONS.md)
- Avancement par lot : [STATUS.md](STATUS.md)
- Journal daté des opérations : [CARNET.md](CARNET.md)
- Architecture du projet : [ARCHITECTURE.md](ARCHITECTURE.md)
- Tests automatiques : [tests/README.md](tests/README.md)

Ce dépôt ne contient que du code, jamais de données saisies.
